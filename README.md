# ARIA, forms, and status messages: practice page

Hands-on practice page for Deque's "Building for Accessibility" Session 2 (ARIA, forms, and status messages).

Live page: https://mdharshbarger.github.io/ilt-aria-practice/

## What's here

- `index.html`: three exercises (disclosure toggle, appointment form, toast messages). Each has editable starter code, a live preview, step-by-step hints, and reference links.
- `form-starter.html`: the broken appointment form as a full page, for scanning with the free Axe DevTools browser extension.

## How learners use it

1. Open the live page and go to the exercise the instructor names.
2. Fix the code on the left. The preview updates as you type.
3. Use "Show a hint" for one hint at a time. "References" has links for after class.
4. Use "Open my code as a full page" to scan your fix with Axe DevTools.

Code edits save in your own browser only. Nothing is sent anywhere.
